Knowledge base documenting infrastructure, windows, linux, networking, automation, and troubleshooting topics encountered in both professional and personal environments.

## About

This repository serves as a centralized collection of:

- Troubleshooting procedures
- PowerShell, Python and Bash scripts
- Linux administration notes
- Networking references
- Docker configurations
- Docker Compose files
- Incident resolutions
- Personal learning notes

The goal is to document solutions and reduce repeated troubleshooting effort.

```text
│
├── windows/

├── monitoring/
├── scripts/
│   ├── powershell/
│   ├── python/
│   └── bash/
│
├── case-studies/
├── homelab/
└── resources/
```

### Directory Overview

- **windows/** - Windows administration, troubleshooting, and reference notes
- **linux/** - Linux administration, commands, and troubleshooting guides
- **networking/** - Networking concepts, diagnostics, and configurations
- **docker/** - Docker and Docker Compose notes and examples
- **monitoring/** - Monitoring, logging, and observability documentation
- **scripts/** - PowerShell, Python, and Bash automation scripts
- **case-studies/** - Sanitized incident resolutions and lessons learned
- **homelab/** - Personal projects, infrastructure, and self-hosting documentation
- **resources/** - Useful references, guides, and external learning materials
